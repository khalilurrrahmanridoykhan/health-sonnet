# Health Sonnet

A small Java 17 Maven project demonstrating a runnable application and a basic JUnit test suite.

## Requirements

- Java 17 or newer
- Apache Maven 3.9 or newer

## Build and test

```bash
mvn clean test
```

Run the application:

```bash
mvn -q exec:java
```

## Project structure

```text
src/main/java/com/example/App.java
src/test/java/com/example/AppTest.java
```
