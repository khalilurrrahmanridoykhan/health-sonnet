# Contributing

Thank you for helping improve Health Sonnet.

## Development

1. Install Java 17 and Maven.
2. Create a focused branch.
3. Run `mvn clean test`.
4. Submit a pull request with a clear summary and test evidence.

## Guidelines

- Keep changes focused and backward compatible.
- Add or update tests for behavioral changes.
- Follow the existing Java formatting and package structure.
- Do not include generated files or build output.
